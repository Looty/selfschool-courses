# Sources

Numbers are stable: lessons and questions cite them as `[n]`. Never renumber; append new sources at the end.
Only list sources that were actually read during research. Never invent a URL.

All pages were read on 2026-11-19 through a fetch tool that returns extracted page text (for some pages a condensed digest, in which case the raw documentation source was also read where the notes say so). `read: full` means the whole page text was retrieved and read; `partly` names what was covered; `abstract only` means only the summary or prototype list was read. Where one entry covers several short pages of the same manual or help centre, the main page is linked and the others are named with their URLs in the Notes line. The Python documentation at docs.python.org/3/ showed version 3.15.2, while HackerRank's Execution Environment page lists Python 3.14.2 for coding questions, so anything marked "Added in version 3.15" must not be assumed available in the interview environment.
