אחרי המעבדה הזו תאמנו מודל של קו ישר בעזרת ירידה במורד הגרדיאנט (gradient descent) בכ-25 שורות קוד, ותראו קצב למידה (learning rate) טוב, איטי ומתפוצץ.

## קיצור דרך: הסקריפט המוכן

הורידו את הקובץ `lab04-gradient-descent.py` מתוך החומרים (Resources) של השיעור. הוא דורש רק את numpy:

```bash
uv venv && uv pip install numpy
python lab04-gradient-descent.py        # learning rate 0.01
python lab04-gradient-descent.py 0.3
python lab04-gradient-descent.py 1.2
```

הוא הורץ בזמן כתיבת הקורס.

## מה הסקריפט עושה

הסקריפט יוצר 50 נקודות רועשות על הישר y = 3x + 2, מתחיל את המודל מ-w = 0, b = 0, וחוזר אלף פעמים על ארבעת השלבים משיעור 16: חישוב פונקציית ההפסד MSE, חישוב שני הגרדיאנטים (הנוסחאות מהקורס המזורז) ועדכון הפרמטרים. [32] הוא מדפיס את ההפסד ואת הפרמטרים בצעדים 1, 10, 100 ו-1000.

## למה כדאי לשים לב

בהרצות הבדיקה, בצעד הראשון ההפסד היה תמיד 13.645, כי המודל ההתחלתי מנבא 0 לכל קלט.

| קצב למידה | אחרי 1000 צעדים | מסקנה |
| --- | --- | --- |
| 0.01 | w = 2.66, b = 2.20, הפסד 0.0235 | עדיין מתכנס: איטי מדי |
| 0.3 | w = 3.05, b = 1.98, הפסד 0.0099 | טוב: הגיע לרצפת הרעש |
| 1.2 | הפסד 9,466,592 בצעד 10 וממשיך לגדול | התפוצץ: כל צעד חורג יותר מהקודם |

ה"אמת" היא w = 3, b = 2, ובנתונים יש רעש, ולכן אי אפשר לצפות לקבל בדיוק 3 ו-2. עם קצב 0.3 התשובה קרובה; עם 0.01 המודל עוד לא הגיע לשם, וזו הסיבה שמכוונים את קצב הלמידה.

## בדקו את עצמכם

- למה ההפסד בצעד 1 זהה לכל קצבי הלמידה?
- עם קצב 1.2 ההפסד גדל בכל צעד. הסבירו זאת במונחים של "חריגה מעבר לתחתית הקערה".
- שנו את הנתונים ל-y = −5x + 10. האם קצבי הלמידה הקודמים עדיין עובדים?

:::key-takeaways
- ירידה במורד הגרדיאנט מתאימה קו ישר בכמה שורות קוד. [32]
- אותו הפסד התחלתי עם קצבי למידה שונים מראה את ההשפעה של גודל הצעד: איטי, טוב או מתפוצץ.
:::

:::glossary
- **numpy**: ספריית Python הסטנדרטית לחישוב מהיר על מערכים של מספרים.
- **רעש (Noise)**: שונות אקראית בנתונים, שאף מודל לא צריך לנסות להתאים אליה במדויק.
- **רצפת הרעש (Noise floor)**: ההפסד הנמוך ביותר שאפשר להגיע אליו כשהנתונים עצמם רועשים.
- **היפר-פרמטר (Hyperparameter)**: הגדרה שבוחרים לפני האימון, כמו קצב הלמידה.
- **כוונון (Tune)**: ניסוי בערכים שונים של היפר-פרמטר כדי למצוא ערך שעובד היטב.
- **התבדרות (Diverge)**: מצב שבו ההפסד גדל במקום לקטון.
:::
