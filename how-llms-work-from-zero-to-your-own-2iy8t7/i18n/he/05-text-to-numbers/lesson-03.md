אחרי המעבדה הזו תהיה לכם טוקנייזר מסוג byte-pair שעובד, בכ-40 שורות קוד, ותראו בעיניים איך אוצר מילים נוצר.

## קיצור דרך: הסקריפט המוכן

הורידו את הקובץ `lab05-bpe.py` מהמשאבים (Resources) של השיעור. הוא משתמש בספרייה הסטנדרטית של Python בלבד:

```bash
python lab05-bpe.py
```

הסקריפט הורץ בזמן כתיבת הקורס.

## מה הסקריפט עושה

הוא פועל לפי האלגוריתם משיעור 21. [6] הוא מתחיל מהתווים של הטקסט `low lower lowest newer newest wider widest low low newer newer`, סופר זוגות סמוכים באמצעות `collections.Counter`, ממזג את הזוג השכיח ביותר וחוזר על התהליך עשר פעמים, או עד שלא נשאר זוג שמופיע יותר מפעם אחת.

## למה לשים לב

בהרצת הבדיקה הטקסט התחיל ב-62 טוקנים, והמיזוגים הראשונים היו:

```
merge  1: 'w' + 'e' -> 'we'   (6x)  now 56 tokens
merge  2: 'l' + 'o' -> 'lo'   (5x)  now 51 tokens
merge  3: ' ' + 'lo' -> ' lo'   (4x)  now 47 tokens
merge  4: 'we' + 'r' -> 'wer'   (4x)  now 43 tokens
```

ואחרי עשרה מיזוגים נותרו 25 טוקנים. לאחר מכן הסקריפט מקודד (encode) טקסט חדש לפי הכללים שנלמדו: `lowest newest` הפך ל-`['lo', 'west', ' ne', 'west']`, והמילה `slowly`, שלא נראתה באימון, הפכה ל-`['s', 'lo', 'w', 'l', 'y']`, כלומר נפלה בחזרה לחלקים קטנים יותר, בדיוק כפי ששיעור 21 צפה. שימו לב ש-`w` + ` lo` הופיע גם הוא כמיזוג: במעבדה הזו ממזגים מעבר לרווחים, ואילו טוקנייזרים אמיתיים נמנעים מכך.

## נסו בעצמכם

- שנו את `NUM_MERGES` ל-3 ואחר כך ל-30. מה קורה למספר הטוקנים ולאוצר המילים?
- החליפו את `TEXT` בפסקה ממסמך שאתם מכירים. אילו חלקים הופכים ראשונים לטוקן יחיד?
- שנו את הסקריפט כך שיפצל קודם לפי רווחים, וכך מיזוגים לעולם לא יחצו גבול מילה. (זה אחד השינויים שטוקנייזרים אמיתיים עושים.)

## בדקו את עצמכם

- למה המיזוג הראשון בוחר ב-`w` + `e` ולא ב-`l` + `o`?
- אחרי עוד מיזוגים הטקסט מתקצר. מה המחיר של אוצר מילים גדול יותר?

:::key-takeaways
- BPE הוא לולאה קצרה: סופרים זוגות, ממזגים את השכיח ביותר וחוזרים על כך. [6]
- טוקנייזר מאומן מקצר את הטקסט ועדיין מתמודד עם מילים שמעולם לא ראה.
:::

:::glossary
- **`collections.Counter`**: כלי ב-Python שסופר כמה פעמים כל פריט מופיע.
- **מיזוג (Merge)**: החלפה של שני טוקנים סמוכים בטוקן חדש אחד.
- **קידוד (Encode)**: המרת טקסט לטוקנים לפי הכללים שנלמדו.
- **אוצר מילים (Vocabulary)**: קבוצת הטוקנים אחרי המיזוגים, בתוספת התווים המקוריים.
- **גבול מילה (Word boundary)**: הקצה שבין מילה אחת למילה הבאה, למשל רווח.
:::
